# Geofencer Changelog

## 2.0.1
* Documentation updates

## 2.0.0
* Created new version of the cdp-geofencer as part of the CUWB 5.1 release.
* Made the geofencer output data over CDP to be consumed by other applications.
* Added extensions that update tag LEDs and enable visible geofencing in the CUWB Viewer.
* Added more configuration options including per-zone hysteresis.

## 1.0.0
* Initial cdp-geofencing release.
